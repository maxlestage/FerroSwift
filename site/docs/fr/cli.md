`ferroswift` traduit un crate Rust en fichiers Swift. Installez-la avec cargo :

```sh
cargo install ferroswift-cli
```

## Les commandes

| Commande | Ce qu’elle fait |
| --- | --- |
| `ferroswift new <nom>` | Crée une app : un crate Rust et son package Swift, puis la traduit. |
| `ferroswift build [crate] [-o <dossier>]` | Traduit `src/**/*.rs` en fichiers Swift. |
| `ferroswift watch [crate] [-o <dossier>]` | Traduit, puis à nouveau après chaque modification d’un fichier Rust. |
| `ferroswift check [crate]` | Signale seulement ce qui ne se traduit pas ; n’écrit rien. |
| `ferroswift file <fichier.rs> [-o <sortie>]` | Traduit un fichier, vers la sortie standard par défaut. |

`crate` est le dossier du crate (le dossier courant par défaut). `ferroswift app.rs` est un raccourci pour `ferroswift file app.rs`.

## Les options

| Option | |
| --- | --- |
| `-o`, `--out <dossier>` | Où écrire les fichiers Swift. |
| `--no-previews` | Laisse de côté les fonctions `#[preview]` (`#Preview` demande Xcode). |
| `-h`, `--help` | Affiche l’aide. |
| `-V`, `--version` | Affiche la version. |

## Où vont les fichiers Swift

Sans `-o`, `build` et `watch` écrivent dans `swift/Sources/<Nom>` quand le crate a un `swift/Package.swift` (l’organisation créée par `ferroswift new`), et dans `swift/` sinon. `<Nom>` est le nom du crate en UpperCamelCase (`my-app` → `MyApp`).

- Chaque fichier Rust devient un fichier Swift qui porte son nom : `src/views/todo_row.rs` → `TodoRow.swift`. `src/main.rs` devient `main.swift` (son `fn main` est appelé à la fin), `src/lib.rs` devient `App.swift`, et un `mod.rs` prend le nom de son dossier.
- Les fichiers sont traduits ensemble : un type, une fonction ou une méthode déclarés dans un fichier sont connus dans les autres.
- `FerroSwiftSupport.swift` contient les aides dont la traduction a besoin, quand elle en a besoin.
- Un fichier n’est réécrit que si son contenu change : Xcode ne recompile pas ce qui n’a pas changé. Les fichiers Swift générés pour des fichiers Rust qui n’existent plus sont supprimés ; les fichiers que vous avez écrits vous-même ne sont jamais touchés (les fichiers générés commencent par `// Generated by FerroSwift`).

## Les diagnostics

Ce qui ne se traduit pas est signalé comme une erreur de compilation, avec le fichier, la ligne et la colonne, la ligne de code et un repère :

```text
error: not supported yet: the macro square!
  --> src/main.rs:6:20
  |
6 |     println!("{}", square!(4));
  |                    ^
```

Une erreur signifie que le Swift produit est incomplet ou ne compilera pas ; un avertissement, qu’il compile mais mérite un coup d’œil. `build`, `check` et `file` se terminent avec un code non nul en cas d’erreur : ils peuvent tourner en CI. `watch` continue et signale chaque nouvelle traduction.

## Dans un script ou en CI

```sh
cargo check                 # la partie Rust compile
cargo test                  # sa logique est testée en Rust
ferroswift check            # tout peut être traduit
ferroswift build -o ios/Generated
```
