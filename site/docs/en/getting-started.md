FerroSwift lets you write an iOS or macOS app in Rust — its logic and its SwiftUI views — and translates it into Swift files that Xcode builds like any other. `cargo check` and rust-analyzer check your code as you type; `ferroswift` writes the Swift.

## Requirements

- **Rust** (stable, edition 2024): [rustup.rs](https://rustup.rs).
- **Xcode 16 or later** (Swift 6) to build the app. On macOS, the Swift toolchain alone is enough to `swift run` it.

The translation itself runs anywhere Rust runs: you can write and check the Rust side on Linux or Windows.

## Install the CLI

```sh
cargo install ferroswift-cli
ferroswift --version
```

## Create an app

```sh
ferroswift new MyApp
cd MyApp
```

`ferroswift new` creates a Rust crate and the Swift package it is translated into, then translates it once:

```text
MyApp/
├── Cargo.toml          the crate, depends on `ferroswift`
├── src/
│   └── lib.rs          your app, in Rust
├── swift/
│   ├── Package.swift   the Swift package (macOS 14, iOS 17)
│   └── Sources/MyApp/  generated by FerroSwift: do not edit
├── .gitignore
└── README.md
```

`src/lib.rs` starts with a first screen and the app itself:

```rust
use ferroswift::prelude::*;

/// The first screen.
#[derive(View, Default)]
pub struct ContentView {
    #[state]
    taps: u32,
}

impl View for ContentView {
    fn body(&mut self) -> impl View {
        vstack()
            .spacing(16.0)
            .child(text(format!("Tapped {} times", self.taps)).font(Font::Title2))
            .child(button("Tap me", || self.taps += 1).button_style(ButtonStyle::BorderedProminent))
            .padding()
    }
}

/// The app: one window.
pub struct MyAppApp;

impl App for MyAppApp {
    fn body(&mut self) -> impl Scene {
        window_group(ContentView::default())
    }
}
```

The functions of the `ferroswift` crate do nothing at run time: they exist so that the compiler, rust-analyzer and the documentation know your views. See [SwiftUI in Rust](../swiftui/).

## Translate

```sh
ferroswift build    # once
ferroswift watch    # again after every save
```

Each `src/**/*.rs` file becomes a `.swift` file in `swift/Sources/MyApp` (`src/views/todo_row.rs` → `TodoRow.swift`), plus `FerroSwiftSupport.swift` when the code needs a helper (Rust-like formatting, a few collection methods). What cannot be translated is reported with its file, line and column, and `ferroswift build` then exits with an error.

Keep `cargo check` (or rust-analyzer) running too: FerroSwift translates code that compiles, it does not replace the compiler.

## Run it

### On macOS

```sh
cd swift
swift run
```

or open `swift/Package.swift` in Xcode and press ⌘R.

### On iOS

1. In Xcode, create a new **iOS App** project (SwiftUI interface).
2. Delete the `ContentView.swift` and `…App.swift` files of the template: your Rust `App` becomes the `@main` app.
3. Drag the `swift/Sources/MyApp` folder into the project and add it to the app target. As a synchronized folder, the files FerroSwift adds or removes appear by themselves.
4. Run `ferroswift watch` in a terminal, then build and run in Xcode.
